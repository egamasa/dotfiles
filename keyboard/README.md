# Keyboard Keymap Settings

VIA/QMK keymap JSON ファイルを管理している。

## ファイル一覧

| ファイル | キーボード |
|---|---|
| `Keychron-K8-Pro-ANSI-White.json` | Keychron K8 Pro（US配列／White LED） |
| `Keychron-B1-Pro-ANSI.json` | Keychron B1 Pro（US配列） |

## 共通事項

### 使用ツール

キーマップの編集・書き込み・エクスポートには [Keychron Launcher](https://launcher.keychron.com/) を使用。

## カスタマイズ

### Keychron K8 Pro

#### Layer 2 / Layer 3 (Windows)

| 物理キー | 送信キー | 説明 |
|---|---|---|
| `CapsLock` | `L ctrl` | CapsLock を Ctrl に変更 |
| `Mic` | `C(KC_D)` | Ctrl+D（Google Meet マイク ON/OFF） |
| `BL` | `BL Toggle` | バックライト点灯 ON/OFF |
| `fn` + `Esc` | `Sleep` | スリープ |
| `fn` + `BL` | `BL Cycle` | バックライト点灯パターン切り替え |
| `fn` + `PgUp` | `BL +` | バックライト輝度 ＋ |
| `fn` + `PgDn` | `BL -` | バックライト輝度 － |

### Keychron B1 Pro

#### Layer 2 / Layer 3 (Windows)

| 物理キー | 送信キー | 説明 |
|---|---|---|
| `CapsLock` / `fn` + `CapsLock` | `L ctrl` | CapsLock を Ctrl に変更 |
| `fn` + `Esc` | `Sleep` | スリープ |
| `fn` + `W` | `↑` | ↑（矢印キー） |
| `fn` + `A` | `←` | ←（矢印キー） |
| `fn` + `S` | `↓` | ↓（矢印キー） |
| `fn` + `D` | `→` | →（矢印キー） |
| `fn` + `[` | `PgUp` | PgUp |
| `fn` + `]` | `PgDn` | PgDn |
